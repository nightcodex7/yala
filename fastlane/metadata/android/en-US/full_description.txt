Manage your OpenWrt routers directly from Android with a modern, high-performance native interface built for everyday administration, wireless monitoring, and advanced network control.

Yet Another LuCI App (YALA) is a privacy-first mobile client connecting directly to your router via standard LuCI HTTP/HTTPS and ubus JSON-RPC APIs. Designed for speed, it provides a touch-friendly alternative to mobile browsers without depending on cloud servers, external accounts, or remote telemetry.

COMPATIBLE FIRMWARES & ROUTERS
Works with stock OpenWrt (19.07–24.10+), ImmortalWrt, Turris OS, GL.iNet, Gargoyle, LEDE, X-WRT, and FriendlyWrt across TP-Link, Netgear, Linksys, Xiaomi, Asus, and custom x86/ARM devices with LuCI or ubus RPC.

KEY FEATURES

MULTI-ROUTER MANAGEMENT & SECURE VAULT
• Manage multiple OpenWrt routers with quick profile switching
• Encrypted local vault backed by Android Keystore
• Supports LuCI RPC, ubus JSON-RPC, and sysauth session logins

CONNECTED CLIENTS & DUMB AP SUPPORT
• Live view of active wired, wireless, and DHCP lease clients
• Dumb AP support: inspect clients connected to secondary bridged APs
• Filter clients by hostname, IP, MAC address, or radio band
• One-tap MAC access control (allowlist / banlist) and static DHCP leases
• Clear IPv4, IPv6, and SSID connection details

PARENTAL CONTROLS & SCHEDULES
• Group devices into customizable parental profiles
• Set access schedules with automatic firewall enforcement
• 1-tap internet pause and resume for individual devices
• Unrestricted bypass mode for temporary overrides
• Activity logs and usage duration metrics

ISOLATED GUEST WI-FI
• 1-tap provisioning of dedicated guest Wi-Fi networks
• Firewall rules isolating guests from your private LAN
• L2 client isolation (ap_isolate) preventing client-to-client snooping
• Wi-Fi QR code sharing for instant guest onboarding

REAL-TIME MONITORING & DIAGNOSTICS
• Live CPU load, RAM usage, swap space, and storage gauges
• Real-time network throughput graphs (Rx/Tx)
• Built-in Ping, Traceroute, and NSLookup diagnostic network tools
• System log inspection and procd daemon status monitoring

WIRELESS NETWORK MANAGEMENT
• Tri-band support for 2.4, 5, and 6 GHz (Wi-Fi 6E/7) radios
• Monitor stations, signal strength (dBm), channel, and noise floor
• Configure SSID visibility, transmit power, and WPA2/WPA3 security

FIREWALL, ROUTING & NETWORKING
• Supports both iptables (fw3) and modern nftables (fw4)
• Enable, disable, or reorder firewall rules, zones, and port forwards
• Inspect interfaces, physical bindings, and switch / DSA topologies

VPN & ENCRYPTED TUNNELS
• Monitor WireGuard, OpenVPN, Tailscale, and ZeroTier tunnels
• Live tunnel handshake status and transfer statistics
• Manage DNS settings (dnsmasq), domain aliases, and upstream resolvers

OPKG & APK PACKAGE MANAGER
• Dual package manager supporting legacy opkg and OpenWrt 24.10+ apk
• Discover, install, update, or remove packages and LuCI apps
• Start, stop, restart, or toggle autostart for system services
• View, add, and edit cron scheduled tasks

SECURITY & SAFETY GUARDRAILS
• Active self-device guard prevents accidental management lockout
• Atomic UCI commits with automatic rollback on network error
• Pre-upload archive header check (gzip/tar) for safe backup restores
• 100% Cloud-Free: Direct local connection with zero ads or telemetry
